CADASTRO DO CÃO COM ABAS: CÃO / PAIS / AVÓS
Não precisa de migração. Este zip substitui o "cadastro-facil.zip" (se já aplicou aquele, pode aplicar este por cima).

1. Copie a pasta "src" deste zip para dentro da pasta spitz (aceite substituir).
2. No cmd, dentro de spitz:
   git add .
   git commit -m "Cadastro do cao com abas Cao, Pais e Avos"
   git push

COMO FUNCIONA
- Plantel > Cadastrar cão abre uma tela com 3 abas: Cão, Pais, Avós.
- Cada aba tem a ficha COMPLETA (nome, registro, nascimento, microchip, cor, porte, fenótipo de cor, DNA...).
- Em TODO cão há a escolha "Meu canil" ou "Outro canil". Cão de outro canil não entra no plantel.
- Para pai e mãe: "Não informar", "Já cadastrado" (escolhe da lista) ou "Cadastrar agora".
- Os avós ficam disponíveis quando o pai/mãe é "Cadastrar agora".
- Se o nº de registro já existe no sistema, o cão é reaproveitado (não duplica).
- Para editar um cão já existente continua valendo a tela de edição anterior.
