LEITURA DE PEDIGREE: opção gratuita (Gemini) + teste de conexão
Não precisa de migração. Este zip é separado: aplique por cima do "cadastro-abas.zip".

1. Copie a pasta "src" e o arquivo ".env.example" para dentro de spitz (aceite substituir).
2. No cmd, dentro de spitz:
   git add .
   git commit -m "Leitura de pedigree com Gemini e teste de conexao"
   git push

COMO USAR O GEMINI GRATUITO (SÓ PARA TESTE)
1. Entre em aistudio.google.com, faça login com sua conta Google e clique em "Get API key" > criar chave.
2. Na Vercel (Settings > Environment Variables) crie GEMINI_API_KEY com a chave. NÃO cole a chave no chat.
3. Faça um Redeploy.
4. Entre como admin > Admin > "Leitura de pedigree (IA)" > "Testar conexão".
   Deve aparecer "Funcionando". Se aparecer erro, o texto diz o motivo (chave inválida, limite, modelo).
5. Só depois do teste ok, vá em Plantel > Importar pedigree e envie UMA foto.

OBSERVAÇÕES
- Se existir ANTHROPIC_API_KEY, ela tem prioridade. Para forçar o Gemini, defina IA_PROVEDOR=gemini.
- O modelo padrão do Gemini é gemini-2.5-flash. Se o teste disser que o modelo não existe, troque
  GEMINI_MODEL na Vercel por um modelo atual listado no Google AI Studio.
- O plano gratuito do Google pode usar o conteúdo enviado para melhorar produtos deles. Use só para
  testar com o seu pedigree. Para clientes reais, use um plano pago (Anthropic ou Gemini pago).
